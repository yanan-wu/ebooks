# 宇树科技主要产品及服务全景：三条产品线、一个组件体系，撑起16.99亿营收

2025年，宇树科技实现营收**16.99亿元**，其中人形机器人收入**8.68亿元**（占比51.07%）、四足机器人收入**6.98亿元**（占比41.05%）、机器人组件收入**1.04亿元**（占比6.10%）。这是宇树在产品层面交出的一份"成绩单"——人形机器人正式超越四足机器人，成为公司第一大产品线。

但营收占比只是结果。真正决定宇树竞争力的，是它构建了怎样的产品矩阵，以及这些产品如何对应到真实场景。本期文章，我们把宇树科技的"产品及服务"拆开，从整机到组件、从消费级到工业级，完整看清这家"人形机器人第一股"到底在卖什么。



## 🏢 业务定位：高性能通用机器人公司

根据宇树科技在科创板上市材料中的官方表述，公司是一家"世界知名、国际领先的高性能通用机器人公司，**专注于高性能通用人形机器人、四足机器人、机器人组件及具身智能模型的研发、生产和销售业务**"。

工商登记的经营范围更为宽泛，涵盖：智能机器人研发与销售、工业机器人制造与销售、服务消费机器人制造与销售、伺服控制机构制造与销售、电池制造与销售、货物及技术进出口等。这说明宇树在法律意义上具备从研发、制造到销售、出口的完整产业链资质。

从产品服务的实际落地看，宇树构建了**"整机+核心组件"**的完整产品矩阵：
- **整机业务**：人形机器人与四足机器人两大核心品类
- **核心组件业务**：关节模组、灵巧手、4D激光雷达、机械臂等
- **配套服务**：SDK开发支持、二次开发接口、OTA升级服务等



## 🤖 第一条产品线：人形机器人（2025年收入8.68亿元）

人形机器人是宇树产品矩阵中**变化最剧烈的一条线**。2023年收入仅296.71万元，2024年跃升至1.07亿元，2025年达到**8.68亿元**，三年增长超过290倍。

根据宇树官网商店与产品页，目前在售的人形机器人主要包括：

### 🔹 Unitree H1 / H1-2：首款全尺寸通用人形机器人

H1发布于**2023年8月15日**，是宇树首款通用人形机器人，也是国内第一台能跑的全尺寸通用人形机器人。关键参数：
- **整机重量**：约47kg（H1）/ 约70kg（H1-2）
- **自由度**：19（H1）/ 27（H1-2）
- **关节极限扭矩**：膝关节约360N.m，髋关节约220N.m
- **运动能力**：移动速度**3.3m/s**（人形机器人世界纪录），潜在运动性能>5m/s
- **感知配置**：3D激光雷达（LIVOX-MID360）+ 深度相机（Intel RealSense D435i）
- **电池**：容量15Ah（0.864KWh），最大电压67.2V
- **售价**：官方商店标价 below $90k（9万美元以内）

### 🔹 Unitree G1：中型人形机器人，9.9万元起售

G1于**2024年5月**发布，起售价**9.9万元**，是人形机器人走向消费级与科研教育市场的关键产品。关键参数：
- **身高/体重**：约132cm / 约35kg
- **自由度**：23（G1基础版）~ 43（G1 EDU版）
- **最大关节扭矩**：120N.m
- **续航**：约2小时
- **感知**：深度相机 + 3D激光雷达 + 4麦克风阵列 + 5W扬声器
- **灵巧手**：可选Dex3-1力控三指灵巧手（7自由度）

G1的可选配Dex3-1灵巧手具备精细操作能力，可完成砸核桃、开汽水瓶、焊接等任务。

### 🔹 Unitree G1-D：双臂工业人形

G1-D是G1的工业衍生版本，采用"立柱+底盘"形态：
- **整机自由度**：17（通用版）/ 19（旗舰版）
- **单臂最大负载**：约3kg
- **底盘移动速度**：最大1.5m/s（旗舰版）
- **续航**：约2小时（通用版）/ 约6小时（旗舰版）
- **高算力模组**：NVIDIA Jetson Orin NX 16GB（100TOPS算力）
- **末端配置**：可选二指夹爪 / 三指灵巧手（无触觉）/ 三指灵巧手（有触觉）/ 五指灵巧手

### 🔹 Unitree R1：轻量化人形机器人

R1是宇树产品矩阵中**最轻量化**的人形机器人：
- **售价**：官方商店标价 **from $4,900**（4900美元起）
- **自由度**：20-26个
- **体重**：约29kg
- **身高**：≤123cm
- **定位**："Ultra-lightweight, fully customizable"（超轻量，完全可定制）

### 🔹 Unitree H2：新一代全尺寸人形

H2是宇树最新的全尺寸人形机器人：
- **身高**：180cm
- **自由度**：31个
- **关节扭矩**：360N.m
- **算力**：2070 TOPS芯片
- **定位**：重新定义工业美学

> 💡 宇树的人形机器人产品矩阵，已经形成"H系列（全尺寸）+ G系列（中型）+ R系列（轻量化）"的完整覆盖，售价从4900美元到9万美元以内，对应科研教育、商业消费、工业应用三大场景。



## 🐕 第二条产品线：四足机器人（2025年收入6.98亿元）

四足机器人是宇树的起家业务。2023-2025年，宇树四足机器人**累计销量超3.3万台**，奠定全球四足机器人市场优势地位。

### 🔹 消费级/科研级：Go2 与 Go2-W

**Unitree Go2**（2023年7月发布）：
- **站立尺寸**：70×31×40cm
- **带电池重量**：约15kg
- **奔跑最大速度**：约5m/s（实验室环境）
- **最大关节扭矩**：约45N.m
- **续航**：约2-4小时（长续航版）
- **感知**：标配4D超广角激光雷达L2（360°×96°半球形超广角，最小探测距离0.05m）
- **载荷**：约8kg（极限约12kg）
- **售价**：**9997元起**

**Unitree Go2-W**：Go2的轮足混合版本，平滑路面移动更快。

### 🔹 工业级：B2、B2-W、A2、As2

**Unitree B2**（2023年11月发布）：
- **最大奔跑速度**：>6m/s（工业级四足机器人全球新纪录）
- **最大关节扭矩**：约360N.m（关节性能提升170%）
- **最大跳远距离**：>1.6m
- **站立负载**：≥120kg；持续行走负载>40kg
- **续航**：空载持续行走>5小时（里程>20km）；20kg负载持续行走>4小时（里程>15km）
- **防护等级**：IP67
- **工作温度**：-20℃ ~ 55℃
- **电池**：45Ah（2250Wh），电压58V
- **整机重量**：约60kg

B2-W是B2的升级版，提升了续航和地形通过能力；**A2**则是另一款工业级四足机器人，空载可连续行走5小时/20km，满载连续行走3小时/12.5km；**As2**是2026年最新发布的紧凑型工业四足机器人。

> 💡 宇树四足机器人的产品逻辑非常清晰：Go2打消费级和科研教育市场，B2/A2/As2打工业级市场，形成从9997元到数十万元的价格梯度。

## 🛠️ 配套服务：让产品真正"能用起来"

宇树的产品不只是硬件，还包括一整套软件与服务：

**1. SDK与开发者支持**
- H1、G1、G1-D等均提供完整的SDK开发指南
- 开发者可使用开发计算单元进行二次开发
- 陆续开源机械臂控制程序及控制接口

**2. OTA升级服务**
- Go2、G1等产品均支持OTA远程升级
- 持续更新运动控制算法、AI能力等

**3. 具身智能模型服务**
- **UnifoLM**（Unified Robot Large Model）通用机器人大模型
- 开源通用WMA模型"UnifoLM-WMA-0"与通用VLA模型"UnifoLM-VLA-0"

**4. 行业解决方案**
根据招股书与公开报道，宇树机器人已落地以下场景：
- **科研教育**：高校、科研机构采购（2025年前三季度科研教育收入5.92亿元，为最大下游应用）
- **商业消费**：Go2消费级机器狗、春晚表演等（2025年前三季度收入3.10亿元）
- **行业应用**：电力巡检、消防侦察、矿山勘探、汽车工厂产线（2025年前三季度收入1.81亿元）
- **标志性案例**：杭州亚运会机器狗运输铁饼和标枪；2026年马年春晚24台G1与1台H2完成全球首次全自主人形机器人集群武术表演



## 写在最后

把宇树科技的产品矩阵摊开看，会发现一个非常清晰的演化逻辑：

**四足机器人**让宇树活下来并成为全球龙头——Go2以9997元的起售价把机器狗带入消费级市场，B2以6m/s的速度和360N.m的扭矩定义了工业级四足机器人的标杆；

**机器人组件**让宇树飞起来——Dex3-1灵巧手、L2激光雷达、M107关节电机等核心组件，正在向行业输出"宇树标准"。

随着H2携2070 TOPS算力芯片登场，随着G1-D双臂工业人形机器人走向工厂产线，随着7.5万台人形机器人年产能目标的推进——宇树的三条产品线，正在从"并行跑"转向"螺旋上升"。
