# 长电科技组织架构：治理层、管理层、业务分部、子公司体系四张图一次看清

> 很多人研究长电科技，习惯直接从“全球OSAT第三”跳到“先进封装订单”——但中间那层「组织架构」反而最容易被忽略。
> 封测是重资产、强协同、客户认证周期长的生意，组织怎么搭，直接决定产能谁调度、研发谁牵头、星科金朋和境内工厂怎么分工、华润入主后治理怎么落。
>
> 截至2026年9月，长电的组织架构可以拆成四层看：**上市公司治理层 → CEO制经营管理层 → A/B报告分部+五大业务板块 → 境内外子公司与八大基地**。



## 一、股权与治理层：华润系通过磐石润企持股22.53%

先定“谁在管”的顶层。

截至2026中报，前两大股东：

- **磐石润企（深圳）信息管理有限公司**：持股 **22.53%**，国有法人，第一大股东
- **香港中央结算有限公司**：3.43%
- 国家集成电路产业投资基金：2.00%
- 其余为指数基金、险资、自然人

磐石润企为华润体系持股平台，2024年大基金、芯电半导体股份转让完成后，长电实控人变更为中国华润体系。 注意准确表述是“磐石润企持股22.53%”，穿透上层可到磐石香港，但上市公司第一大股东名册写的是磐石润企。

治理架构按A股常规三会：

- **股东大会** → 最高权力机构
- **董事会** → 经营决策与战略
- **监事会/审计委员会等专门委员会** → 监督与风控

## 二、经营管理层：CEO制+职能VP，不按事业部总经理制写

长电公开披露的管理层不是“各产品事业部总经理并列”，而是**CEO统管+执行副总裁/CFO/董秘+各职能高级副总裁**。

可确认的核心经营班子：

- **郑力**：CEO，管整体业务、战略客户、先进封装方向
- **彭庆**：执行副总裁，非独董
- **梁征**：首席财务长（CFO），管财务、资本开支、投资人关系
- **袁燕**：副总裁、董秘，管披露与投资者沟通
- **吴宏鲲**：副总裁（2026半年报业绩会出席名单）
- 历史披露中还有销售、人力资源、法务、战略发展等高级副总裁序列 



经营层实际分工逻辑：
- CEO管战略客户+技术方向
- CFO管资本开支（2026固投约100亿）+财报
- 执行副总裁管运营/业务线
- 董秘管合规披露
- 各VP按职能（销售、HR、法务、战略）横向支撑



## 三、业务组织：A/B报告分部 + 五大应用 + 五类技术板块

这一层是长电“组织架构”里最有业务含义的部分。

### 1. 报告分部：A板块 / B板块（星科金朋）

2026半年报把内部业务分为两个报告分部：

- **A板块**：除星科金朋集团外的其他子公司（境内为主：江阴、滁州、宿迁、先进封装、微电子等）
- **B板块**：STATS ChipPAC Pte.Ltd.（星科金朋）及其子公司（新加坡、韩国、江阴厂、日本等）

上半年数据：
- A板块对外收入 **127.49亿**，净利润3.76亿
- B板块（星科金朋）对外收入 **69.98亿**，净利润 **4.47亿**

结论很直观：**星科金朋以约36%的收入贡献了约54%的净利润**，是国际客户+高端封装利润中心；A板块是产能基本盘+国产替代订单承接方。

这也是组织设计的重点——**长电不是把星科金朋“并进来就完事”，而是单独作为B分部核算**，保留海外产能与客户通道，同时和境内工厂做订单协同。

### 2. 应用市场组织：五大领域组合管理

公司对外按应用领域拆业务结构（2026H1占比）：

- 运算电子 **30.1%**（第一大）
- 通讯电子 27.4%
- 消费电子 23.2%
- 汽车电子 11.1%
- 工业及医疗 8.2%

内部“面向应用”的开发机制：2023年设**工业和智能应用事业部**，以整体解决方案为核心，服务HPC、AI、工业自动化客户。

所以长电的业务组织不是纯“按封装形式排部门”，而是：
**封装技术平台（横向）× 应用事业部（纵向）× 客户协同设计**

### 3. 技术板块组织：五类组合管理

业绩说明会里公司明确“内部按五大板块进行组合管理”：

1. 高端先进封装（XDFOI、2.5D/3D、大颗FCBGA）
2. 先进封装（FC、WLP、部分SiP）
3. 系统级/模组封装（SiP、AiP、电源模组）
4. 主流封装（QFN、SOP、引线框架）
5. 测试（晶圆中测、成品测试、系统级测试）

资本开支分配（2026H1）：
- 主流封装投入不到一成
- 剩余大部分去先进封装/模组/测试
- **高端先进封装占资本开支一半以上** 

这五类不是独立法人，也不是工商登记的“事业部”，而是**内部组合管理口径**——用来分配产能、研发、销售资源和KPI。

## 五、组织演进的三个关键节点

把历史串一下，能看懂今天的结构怎么来的：

**① 2015收星科金朋**
获得B板块（海外基地+国际客户），从此组织变成“境内A+海外B”双轨。

**② 2023设工业和智能应用事业部**
从“按封装形式接单”转向“按应用场景做整体方案”，HPC/AI/工业客户早期进场。

**③ 2024华润入主 + 2024收晟碟 + 2026临港新厂**
股东层变央企背景；存储封测补强；汽车电子与高端先进封装单独建主体（JSAC、长润芯微）。

组织结果：
- 治理层：华润系大股东+CEO制
- 业务层：A/B分部+五应用+五技术板块
- 产能层：境内全资基地+星科金朋+专项子公司
- 研发层：上海创新中心+基地平台+参股先导中心



## 六、一句话总结组织画像

长电科技的组织架构 =
**华润系通过磐石润企持股22.53%的上市公司治理层**
+ **郑力CEO制经营层**
+ **A板块（境内）/B板块（星科金朋）双报告分部**
+ **运算/通讯/消费/汽车/工医五应用 × 高端先进封装/先进/SiP模组/主流/测试五板块**
+ **江阴滁州宿迁+上海临港+新加坡韩国基地+专项子公司（JSAC 55%、晟碟80%、长润芯微）**。

它不是一个“封测车间集合”，而是**央企股东背景下的全球OSAT平台型组织**——境内工厂吃国产替代与先进封装扩产，星科金朋吃国际客户与高端订单，应用事业部做客户早期协同，五类技术板块做资本开支分配。

看长电的组织，本质是在看一件事：
**重资产封测公司怎么同时调度“境内产能、海外产能、先进封装研发、车规新厂、存储并购”五张牌**——答案就在A/B分部+五板块组合管理里。
