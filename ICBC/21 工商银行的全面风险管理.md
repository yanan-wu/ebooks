# 工商银行的全面风险管理：管住人、管住钱、管好防线、管好底线


> 2025年末，工行不良贷款率**1.31%**，较年初下降3个BP；拨备覆盖率**213.6%**，贷款拨备余额**8523亿元**，较年初增加368亿元；资本充足率**18.76%**、一级资本充足率14.94%、核心一级资本充足率13.57%；流动性覆盖率**138.61%**、净稳定资金比例**126.35%**——这一组指标，是工行53.48万亿资产规模的"安全垫"，也是"宇宙行"之所以能称为"维护金融稳定的压舱石"的底气所在。

在低利率周期、房地产调整、全球市场波动的三重压力下，拆工行这套全面风险管理体系，看的不是某一项指标的高低，而是**它如何在"9+X"类风险、境内外49国、16246个机构、7.82亿个人客户、1474万户对公客户的复杂棋盘上，做到"早识别、早预警、早暴露、早处置"**。



## 一、治理架构：纵向统筹+横向三道防线的"一体两翼"

工行全面风险管理体系的"骨架"，在2025年资本管理第三支柱报告中写得明明白白——

**🏛 董事会及下设风险管理与内部控制委员会**
董事会持续加强对宏观形势的跟踪研判，审议年度经营计划、风险偏好评估、流动性风险管理等议案，修订《全面风险管理规定》《有效风险数据加总和风险报告管理办法》《数据安全管理办法》等制度办法。

**🧭 高级管理层：首席风险官牵头**
在高级管理层中设立首席风险官，**牵头负责全面风险管理工作**；高级管理层风险管理与内部控制委员会是研究、讨论和决策风险管理和内部控制重要事项的议事机构。

**🎯 各类风险"分头牵头"的责任分工**
这是工行风控体系最值得称道的设计——**每一类风险都有明确的"主人"**：

| 风险类别 | 牵头管理部门 |
|---|---|
| 信用风险 | 信贷与投资管理部 |
| 市场风险、国别风险、气候风险 | 风险管理部 |
| 操作风险、合规与洗钱风险 | 内控合规部 |
| 流动性风险、银行账簿利率风险 | 资产负债管理部 |
| 声誉风险 | 办公室 |
| 战略风险 | 深改办 |
| 信息科技与网络安全风险 | 金融科技部、内控合规部、风险管理部 |
| 运营风险 | 运行管理部 |
| 安全生产风险 | 安全保卫部 |
| 数据安全 | 数据管理部 |

数据源自工行2025年资本管理第三支柱披露报告

**🛡 三道防线联防联控**
工行坚持**纵向风险管理与内部控制委员会、风险官、风控部门贯通统筹，横向三道防线联防联控**。一道防线风控责任持续强化，内控、审批、审计新规深化落地——这种"纵向到底、横向到边"的网格化架构，是工行管理53.48万亿资产的制度前提。

💡 同业视角：许多银行的风险管理停留在"风险部管一切"的集中模式，而工行"9+X"类风险分头牵头的机制，确保了每一类风险都有专业部门深度经营。这正是"大银行"避免风险管控"灯下黑"的关键设计。



## 二、风险文化："四管齐下"与"全面管、主动防、智能控"

工行2025年全面风险管理的核心方法论，可以浓缩为两组关键词：

**第一组：管住人、管住钱、管好防线、管好底线——"四管齐下"**
- **管住人**：抓牢关键人员，完善履职评价机制
- **管住钱**：对全量资产进行大类摆布、大块切分
- **管好防线**：三道防线联防联控
- **管好底线**：风险早识别、早预警、早暴露、早处置

**第二组：全面管、主动防、智能控——"三字路径"**
- **全面管**：统筹强化"9+X"各类风险管理
- **主动防**：按照"三道口、七彩池"智能信贷风控体系，在准入、存续期、处置三大环节主动防御
- **智能控**：依托金融科技，加快由人防人控向技防智控转变

风险文化层面，工行积极培育"五要五不"中国特色金融文化，秉承"依法合规、稳健务实、诚信严谨、专业协作、人人尽职"的风险文化核心价值——这套文化不是墙上的标语，而是贯穿在133项内控具体措施、完成率100%的执行里。



## 三、信用风险：从"三道口、七彩池"到AI智能体矩阵

信用风险是工行作为"宇宙行"面临的最大风险类别。2025年的核心数据：

**📊 资产质量关键指标**
- 不良贷款率**1.31%**，从2021年的1.42%累计下降11个BP
- 拨备覆盖率**213.6%**，贷款拨备余额**8523亿元**
- 关注类贷款占比**1.95%**，比上年末下降7个BP
- 逾期贷款占比**1.52%**，逾期90天以上贷款与不良贷款的比例**83.31%**
- 2025年核销及转出不良贷款**1199.58亿元**

**🏗 "三道口、七彩池"智能信贷风控体系**
工行副行长王景武在中期业绩会上详解了这一体系：
- **准入环节**：构建"行业—区域—产业链"三维政策体系，有序推动二级分行授信审批新规落地
- **存续期管理环节**：持续加强存续期管理，做好重点领域风险防范化解
- **处置环节**：高质量运行风险资产直营直管工作机制

**🤖 智能风控的"工行范式"**
这是2025年工行信用风险管理最具突破性的进展：
- **企业级智能风控平台全面投产**，覆盖**近300个风控决策场景**
- **"4E中心"（风险视图、计量、预警、决策）全面覆盖总行和分支机构**
- **"智贷通"**：新一代融资全流程智能体矩阵，覆盖制度解答、业务营销、客户分析、风险排查监测4类场景、20余个智能体
- **"工小审"**：信贷评审AI数字助手，财务风险分析效率提升**20%**
- **企业信用风险智能评估专属大模型**：通过对基础大模型的风控能力强化训练，显著提升风险客户识别的准确率和召回率

**🏢 信贷结构的"均衡术"**
2025年末工行前五大贷款行业（交通运输仓储和邮政业13.79%、租赁和商务服务业9.45%、制造业9.35%、电力热力燃气及水6.47%、水利环境公共设施管理业6.31%）合计占比**45.37%**，行业集中风险不显著。
- 单一最大客户贷款比例**4.4%**，最大十家客户贷款比例**19.4%**
- 抵质押贷款占比**51.1%**，信用贷款占比**39.9%**，保证贷款占比**9.0%**
- 总贷款/总存款**81.76%**



## 四、重点领域风险防控：房地产、地方债、中小金融机构

**🏠 房地产：5.39%不良率下的"精准拆弹"**
2025年末工行境内分行房地产业贷款**8645.76亿元**，不良贷款率**5.39%**，较上年末有所上升且高于全行平均水平。房地产业贷款在对公贷款中占比**4.92%**。
工行的应对：
- 落实城市房地产融资协调机制，支持保交房项目数、贷款额均同业领先
- 保持房地产领域投融资业务余额总体稳定
- 2025年中期向**400多家中小金融机构**提供风控技术和系统

**🏛 地方政府债务：市场化、法治化化债**
坚持市场化、法治化原则，稳妥有序开展金融支持化债工作，加大重点区域化债工作力度。

**🤝 中小金融机构：输出风险管理技术**
向中小金融机构输出风险管理技术，共筑金融安全防线——这是工行作为"系统重要性银行"的行业责任。



## 五、市场、流动性与利率风险：138.61%的流动性覆盖率

**🌊 流动性风险管理**
2025年末关键指标：

| 指标 | 监管要求 | 2025年末 | 2024年末 |
|---|---|---|---|
| 流动性比率（人民币） | ≥25% | **63.2%** | 58.4% |
| 流动性覆盖率 | ≥100% | **138.61%** | 140.25% |
| 净稳定资金比例 | ≥100% | **126.35%** | 128.16% |

工行的流动性管理策略是"稳健审慎"——加大资金监测力度，保持合理充裕的流动性储备；推动流动性风险管理机制和系统不断升级；加强境内外、表内外、本外币流动性风险管理。

**📊 利率风险：银行账簿利率风险管控**
在低利率周期里，工行持续加强银行账簿利率风险管理，2025年净利息差1.15%、净利息收益率1.28%——在六大行中保持中上水平，体现了对利率风险的主动管理成效。

**💱 市场风险：五大市场智能预警**
企业级智能风控平台已实现对商品、外汇、债券、货币、股票**五大市场风险智能化排查预警**。



## 六、资本管理：18.76%资本充足率的"缓冲垫"
